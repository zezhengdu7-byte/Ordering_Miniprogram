企业主体月均固定预算 199 + 300/12 = 224 元；个体户 199 + 30/12 = 201.5 元。不含超额资源、另购数据库/服务器、硬件、打印平台服务/4G流量、耗材、域名及开发维护。月小程序收款 10 万元按 0.6% 为 600 元，合计约 824 元或 801.5 元。每个环境若另购资源应额外计算，不能把云托管+独立 PostgreSQL 的全部费用都视为已含在套餐内。

CloudBase 官方产品页将微信支付集成列入标准版能力。个人版能否满足选定的自行调用支付 API 方案，需在实现前核实；不预先承诺 19.9 元能完成正式收款。免费档与活动价不能当作永久生产价格。

## 多门店规划

多店可共享一个 CloudBase 环境，但共享调用、流量、存储等配额，不代表店数无限且不增加费用。也可按门店独立环境，隔离运维和账单。前端 AppID 和后端环境是两种不同资源：一个平台小程序可进入不同门店；各店独立品牌小程序则需要各自 AppID 和认证/发布。

正式后端应为门店、分区、菜品、桌台、用餐会话、员工、购物车、订单、支付和打印任务建立门店归属。所有 API 必须验证门店成员关系/用餐成员关系，不信任前端提供的 store_id，不把隐藏页面当作权限保护。支付回调须从可信订单记录反查门店与商户配置；各店收款身份和资金流需单独确定。多 AppID 下的 OpenID 不能直接等同为同一用户。

Demo 的单店本地数据结构并未实现上述租户安全机制。正式开发时统一将本地 store 模块替换为带权限的业务 API，并实现事务、幂等、断线重连、可信支付确认、持久化打印任务和失败恢复。
